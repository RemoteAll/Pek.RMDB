## 1. 项目速览

- 定位：C# `Pek.MDB` 的 Rust 实现（**高性能内存数据库库**，crate `pek-rmdb`）。
- 参照：`G:\Code\Pek.FrameWork\Pek.MDB`（`Data/Cache/MemoryDB.cs`、`TypedIndex/*`、`UniqueConstraintManager.cs`、`Serialization/*`、`_ding/cdb.cs`）。
- 远程仓库：`https://github.com/RemoteAll/Pek.RMDB.git`（remote 名 `origin`，分支 `main`，已推送）。
- 版本：`0.1.0`（首轮实现）。

## 2. 常用命令（构建 / 测试 / 回归）

```powershell
cargo check
cargo test
cargo clippy --all-targets -- -D warnings
cargo test --release --test perf_guard -- --ignored --nocapture --test-threads=1
cargo zigbuild --target x86_64-unknown-linux-musl --lib   # 交叉检查（需 zig）
```

- 日常写码用 `cargo check`；需要二进制用 `cargo build --profile fast`；`--release` 只用于发布/基准。
- 依赖下载走项目内 `.cargo/config.toml`（rsproxy 镜像）。
- **PowerShell 5.1 会把 cargo 的 stderr 当错误**：`2>&1 |` 后退出码可能为 1，但测试实际通过，以输出中的 `test result` 为准。

## 3. 目录约定

```
src/{lib,error,value,model,index,unique,table,db,persistence,json}.rs
tests/{common,crud,index,unique,persistence,concurrency,perf_guard}.rs
docs/{项目接续指南,用户档案,项目记忆,决策记录,审计报告,与C#对照}.md
tools/continuity/*
```

模块职责：

| 模块 | 职责 |
|---|---|
| `value` | `FieldValue`/`FieldKind`、类型规范化、时间解析、JSON 文本 |
| `model` | `CacheObject` trait、`Field`/`UniqueRule`/`CompositeUniqueRule`、分页与统计结构 |
| `index` | 类型感知索引（`BTreeSet` ID 集合、`BTreeMap` 有序范围、文本大小写不敏感索引） |
| `unique` | 唯一约束（两阶段原子写入、复合键、allow_null） |
| `table` | 单表（`RwLock<State>`：主存储 + 索引 + 唯一索引 + ID 计数器 + 脏标记） |
| `json` | 实体序列化/反序列化（C# `SimpleJsonString` 契约）；通用宽松解析/转义复用 `dhrust::json` |
| `persistence` | 原子写 + 写合并调度原语（条件变量，零轮询） |
| `db` | `MemoryDb` 门面、多实例/全局单例、后台线程、统计 |
