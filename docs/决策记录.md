**权衡**：FxHash 不抗 HashDoS；本库键来自可信业务实体，已在 `hash.rs` 模块文档写明"若引入不可信键需换回 `RandomState`"。

## 2026-10-25（三）通用 JSON 能力下沉 DH.RustBase

**用户原话**

> 当前项目json.rs不用提取到DH.RustBase项目么？

**结论**：下沉。`json.rs` 的两类职责拆开：

| 内容 | 去向 | 理由 |
|---|---|---|
| `JsonValue` + 宽松解析（裸键、`//` 注释、尾逗号、Unicode 转义） | `dhrust::json::{JsonValue, parse_lax}` | 与实体无关，任何解析 C#/第三方宽松 JSON 的项目都需要；dhrust 原 `json` 模块只有 serde_json 取值工具，缺完整解析器 |
| JSON 字符串转义（C# `ClearNewLine` 口径） | `dhrust::json::write_quoted` | 通用文本能力，避免各项目再写一份 |
| 实体列表序列化/反序列化（`serialize_snapshot`/`parse_entities`）、`FieldKind` 强制转换 | 保留在 `pek_rmdb::json` | 与 `CacheObject`/`FieldValue` 强耦合，属本项目持久化契约 |

**改动**

- `DH.RustBase/src/json.rs`：新增 `JsonValue`（`get` 大小写不敏感、`as_*`/`to_*` 宽松转换）、`parse_lax`、`write_quoted`，附 6 项单元测试（原 5 项取值测试保留）；
- `Pek.RMDB/src/json.rs`：删除本地解析器与转义（约 330 行），改为 `dhrust::json::{parse_lax, write_quoted, JsonValue}`；`pek_rmdb::json::JsonValue` 仍可访问（`pub use`）；`parse` 保留为公共包装；
- `Pek.RMDB/src/value.rs`：删除本地 `write_quoted`，改用 `dhrust::json::write_quoted`；
- 文档：本项目依赖表/模块表/审计报告同步说明。

**回归**

- DH.RustBase：`cargo test --lib json::` 11 项全绿；`cargo clippy --all-targets -- -D warnings` 零告警；
- Pek.RMDB：`cargo test` 69 项全绿（单元 20 + 集成 48 + 文档 1；解析器测试已随下沉迁入 DH），`clippy -D warnings` 零告警；
- 行为不变：C# 旧文件加载、Rust 裸键输出、注释/尾逗号/代理对测试均由 DH 新测试 + RMDB 持久化测试覆盖。

**提交**

- `DH.RustBase`：`e46b5c1`（`feat(json): 下沉 C# 兼容宽松解析与转义（Pek.RMDB 消费）`）；
- `Pek.RMDB`：`709ec41`（`refactor(json): 通用宽松解析/转义下沉 DH.RustBase（dhrust::json）`）。

## 2026-10-25（二）v0.1.0 实现落地（完整功能 + 性能优化 + 审计 + 接续基建）

**用户原话**

> G:\Code\Pek.FrameWork\Pek.MDB帮我参考这个项目实现Rust版本的，另外要参考现有的项目实现全局用户指令。而且也要考虑性能上的优化调整，并做好审计。

**实现（`pek-rmdb` v0.1.0）**

| 模块 | 内容 |
|---|---|
| `value` | `FieldValue`（Null/Bool/Int/Float/Text/Time/List/Map）+ `FieldKind`；按字段类型规范化（跨类型查询命中）；C# 兼容时间解析（`dhrust::times` + 斜杠日期 + Unix 秒/毫秒） |
| `model` | `CacheObject` trait（`type_name/id/name/fields/composite_uniques/get_field/set_field/not_save`）；`const fn` 字段构造器与唯一约束修饰器；`PagedResult`/统计结构 |
| `index` | 文本（精确区分大小写 + 小写 `BTreeMap` 大小写不敏感/前缀范围/通配）、数值/时间（`BTreeMap::range`）、布尔（双桶 + 智能值）、JSON（文本键）；ID 集合 `BTreeSet<i64>` |
| `unique` | 单字段/复合唯一索引；**两阶段原子写入**（先全部校验、再统一落索引）；`allow_null`；更新排除自身 |
| `table` | 整表 `RwLock<State>`：主存储 + 普通索引 + 唯一索引 + ID 计数器 + 加载标记；读并发、写单写者 |
| `json` | 手写序列化（C# `SimpleJsonString` 风格：裸键/`\r\n`+`\t`/`Name` 在前）+ 宽松解析（注释、尾逗号、裸键/引号键、Unicode 转义） |
| `persistence` | `write_atomic`（临时文件 + `dhrust::io::safe_replace_file`）；`PersistHub` 条件变量 + 最小写盘间隔（500ms 合并，零轮询） |
| `db` | `MemoryDb` 多实例/`global()` 单例；惰性建表与加载；`DbOptions`（目录/后台开关/间隔/缩进/Drop flush/错误回调）；自由函数对齐 `cdb` 风格 |
| 测试 | 单元 21 + 集成 48（CRUD 15 / 索引 9 / 唯一 9 / 持久化 11 / 并发 4）+ 文档 1；`perf_guard` 基准 1（ignored） |
| 接续基建 | `.github/copilot-instructions.md`、`docs/{项目接续指南,用户档案,项目记忆,决策记录,审计报告,与C#对照}.md`、`tools/continuity/*`（自检/记忆同步/跨仓提交 + 用户级指令模板）、`.vscode/tasks.json`（打开项目自检） |

**关键设计选择**

1. **不使用 serde**：C# 持久化是裸键 JSON，标准解析器读不了；手写解析器同时支持 C# 与标准 JSON，写出保持 C# 兼容（双向互通）。
2. **无反射字段描述**：Rust 无反射，实体用 `fields()` 静态描述 + `get_field`/`set_field` 手写映射（约 10 行样板）。
   后续可选 proc-macro 派生（列入待办）。
3. **索引 ID 集合用 `BTreeSet`**：首版用 `Vec` + 线性去重，低基数字段（`Status` 只有 2 个取值）插入退化为 O(k)：
   10 万行时插入 20.8µs/行、更新 88µs/行。改 `BTreeSet` 后 **6.9µs/行、11.2µs/行**（插入 3.0×、更新 7.9×），迭代有序也让分页/范围顺序稳定。
4. **索引分页**：`find_by_page` 优先按有序索引取“前 N 条”（`O(page)`），索引未覆盖全表才退回全量排序；实测 9µs/页。
5. **写合并 + 不丢尾写**：写盘开始时先“取走”脏标记，写入期间的修改重新置脏，下一轮补写（C# 版 500ms 内直接 return，可能丢最后一次修改）。

**修复的 C# 缺陷（详见 `docs/与C#对照.md`）**

- 加载后 ID 计数器未修正 → 新增从 1 开始覆盖旧数据（Rust 取 `max(id)+1`）；
- 加载唯一冲突只警告、对象仍在表中但唯一索引缺失（Rust 跳过该对象）；
- `FindById` 前未触发文件加载（Rust 首次访问表即加载）；
- `NumericIndex`/`StringIndex` 范围查询全量遍历（Rust `BTreeMap::range`，`O(log n + k)`）；
- `FindByPage` 反射 + 全量排序（Rust 索引分页）；
- 通配符“ab”能匹配“abc”（Rust 修正为完整消耗文本）；
- 字符串索引 `Name` 未转义（Rust 转义引号/反斜杠、去换行）。

**验证**

- `cargo test`：70 项全绿（21 单元 + 48 集成 + 1 文档；`perf_guard` 与 1 个示例文档测试默认忽略）；
- `cargo clippy --all-targets -- -D warnings`：零告警；
- Release 基准（10 万行 / 10 索引 / 3 唯一）：插入 6.9µs/行、`find_by_id` 133ns、`find_by_unique` 429ns、`update` 11.2µs、分页 9µs、并发读 767 万次/秒；
- 数据文件与 C# 格式互通（测试覆盖：C# 裸键 + 注释 + 斜杠日期文件加载、Rust 输出裸键断言）；
- 接续自检脚本：`OK：已是最新（版本 2026.10.24.5）`。

**提交**

- `Pek.RMDB`：`505876d`（`main`，已推送 `https://github.com/RemoteAll/Pek.RMDB.git`）。
